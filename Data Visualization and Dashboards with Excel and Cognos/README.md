# Data Visualization and Dashboards with Excel and Cognos
**Completed:** March 2025 | **IBM Data Analyst Professional Certificate**

---

## 📊 Course Overview
This module within the IBM Data Analyst Professional Certificate transitions raw data analysis into visual storytelling and business intelligence (BI). The curriculum focuses on selecting appropriate chart types, designing effective user interfaces, and creating comprehensive, interactive dashboard layers. 

Through standard spreadsheet visualization tools in Microsoft Excel and enterprise-grade BI software via IBM Cognos Analytics, this course culminates in a capstone project where I developed multi-page interactive dashboards to communicate key business performance metrics to organizational stakeholders.

---

## 🎯 Key Findings
* **Operational Distribution:** (Example) Identified that over [X%] of sales volume or customer issues were concentrated within a single demographic group or region, exposed via geographical and treemap visualizations.
* **Macro Trends:** Recognized distinct historical spikes and cyclic patterns by pairing traditional line charts with moving averages to smooth out daily operational noise.
* **Metric Cohesion:** Discovered that a drop in [KPI A] strongly preceded an increase in [KPI B], providing a leading indicator framework for management teams.

## 📊 Data Sources
The primary datasets were sourced from IBM Skills Network, designed to model typical enterprise operations (such as web traffic, retail performance, or HR attrition metrics). The data incorporates hierarchical structures ideal for practicing drill-down analytics, filtering, and cross-tabulations.

---

## 💡 Key Skills Demonstrated
- **Visual Communication Design** - Applying clean design principles (proper use of color theory, layout hierarchy, and white space) to maximize dashboard readability.
- **Chart Selection Logic** - Choosing matching visual structures for data types (e.g., Treemaps for nested categories, Scatter plots for correlations, and Line graphs for chronological metrics).
- **Enterprise Business Intelligence** - Managing data assets inside an enterprise BI platform (Cognos), building data modules, and establishing interactive filter relationships across multiple visualization widgets.
- **Interactive Control Architecture** - Wiring up unified slicers, timelines, and drop-down selectors to allow non-technical business leaders to easily self-serve data filters.
